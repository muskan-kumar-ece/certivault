# CertiVault v1.1 & Future Roadmap Backlog

**Source:** `docs/PRD.md` §5, ADR Decisions, and Early Beta Feedback  
**Status:** Post-v1.0 Planning  

---

## 1. v1.1 Scope (Weeks 9–14 Post-Launch)

### 1. Multi-Stage Approval Workflow
- **User Story:** As an Exam Controller or Dean, I want to review and approve a batch drafted by a student coordinator before credits are consumed and emails are dispatched.
- **Implementation:**
  - New batch status: `draft` -> `pending_approval` -> `approved` / `rejected` -> `queued`.
  - Notification to organization owners/admins when a batch requires review.
  - Diff view showing sample certificates and total credit impact.

### 2. WhatsApp Notification Delivery (Paid Add-On)
- **User Story:** As a hackathon lead, I want recipients to receive their certificate link directly on WhatsApp via a verified business account.
- **Implementation:**
  - Gupshup / Twilio WhatsApp Business Cloud API integration.
  - Templated WhatsApp message with interactive button: "View & Download Certificate".
  - Dedicated delivery log tracking `sent`, `delivered`, `read`, and `failed`.
  - Pricing: ₹0.50 per WhatsApp notification credit.

### 3. "Add to LinkedIn" 1-Click Credential Button
- **User Story:** As a recipient on `/c/[publicId]`, I want to add my verified certificate to my LinkedIn profile's "Licenses & Certifications" section with one click.
- **Implementation:**
  - Standard LinkedIn Certification URL generation (`https://www.linkedin.com/profile/add?startTask=CERTIFICATION_NAME...`).
  - Automatically populated with Certificate Name, Issuing Org Name, Issue Date, Expiration Date, Credential ID (`CV-YY-XXXXXXXX`), and Verification URL.

### 4. Custom Subdomain Verification (`verify.college.ac.in`)
- **User Story:** As a Campus Plan subscriber, I want my public certificates verified under my college's branded subdomain with SSL.
- **Implementation:**
  - Vercel Custom Domains API or Cloudflare for SaaS custom hostname dispatch.
  - Multi-tenant host header routing in Next.js middleware / server components.

### 5. PDF Cryptographic Hash & Fingerprint Verification
- **User Story:** As an employer, I want to upload a PDF directly to the verify page to verify whether its SHA-256 fingerprint matches the original stored document.
- **Implementation:**
  - Compute SHA-256 hash of base PDF bytes on generation and store in `certificates.pdf_sha256`.
  - Client-side drag-and-drop hash calculator on `/verify` matching against database records without full file upload.

### 6. Scheduled Batch Issuance & Timed Sends
- **User Story:** As an event organizer, I want to upload and prepare the batch on Thursday but schedule issuance for 6:00 PM Sunday post-valedictory.
- **Implementation:**
  - `batches.scheduled_for timestamptz`.
  - Worker filter: `WHERE (scheduled_for IS NULL OR scheduled_for <= NOW())`.

### 7. Smart AI Column Matching (Optional Feature-Flagged)
- **User Story:** When importing an unconventional Excel file, I want an optional AI assist to automatically map column names to template fields.
- **Implementation:**
  - Behind `AI_ENABLED=true` environment flag.
  - Strict client opt-in; zero LLM calls in core generation hot path.

## 2. v2.0 Scope (Long-Term Horizon)

- **Public Developer API & Webhooks:** RESTful API with scoped API keys (`cv_live_...`) for issuing certificates programmatically from LMS platforms (Moodle, Canvas, Blackboard).
- **Recipient Digital Credential Wallet:** Mobile PWA wallet for students to aggregate all their certificates from various colleges and clubs.
- **Single Sign-On (SSO):** SAML 2.0 / OIDC enterprise authentication for universities (Google Workspace, Microsoft Entra ID).
- **Verifiable Credentials & Open Badges:** W3C Verifiable Credentials and Open Badges 3.0 export compliance.
- **Physical Certificate Print & Dispatch:** Partnership with national print fulfillment providers for tamper-evident embossed certificate delivery.
